# 🌙 RPG Anime — Não Desista, Meu Amor

Um mini RPG interativo em estilo anime, criado com **HTML, CSS e JavaScript**. O projeto transforma uma mensagem de carinho e apoio em uma pequena aventura dividida em capítulos, com escolhas, estrelas, memórias e uma surpresa no final. 💙✨

## 🎮 Sobre o projeto

A experiência começa com um prólogo e conduz o jogador por diferentes etapas. Durante a aventura, ele pode escolher como está se sentindo, encontrar cinco memórias escondidas nas estrelas, ler uma carta especial e concluir a missão final.

O objetivo do projeto é transmitir uma mensagem de apoio, esperança e companhia de uma forma criativa e interativa.

## ✨ Funcionalidades

- 🌌 Interface inspirada em anime e RPG
- 💬 Escolhas interativas de emoções
- ⭐ Missão para encontrar 5 estrelas/memórias
- ❤️ Sistema visual de HP e XP
- 💌 Carta especial durante a aventura
- 🎵 QR Code que direciona para uma música no YouTube
- 💗 Animação de corações e estrelas no final
- 🔄 Botão para jogar novamente
- 📱 Layout adaptável para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura do jogo
- **CSS3** — aparência, animações e estilo anime/RPG
- **JavaScript** — interações, escolhas, progresso e efeitos

## 📁 Estrutura do projeto

```text
RPG-ANIME/
├── index.html   # Estrutura e conteúdo da aventura
├── style.css    # Estilos, layout e animações
├── script.js    # Lógica e interações do jogo
└── README.md    # Documentação do projeto
```

## 🚀 Como executar

1. Baixe ou clone o projeto.
2. Mantenha `index.html`, `style.css` e `script.js` na mesma pasta.
3. Abra o arquivo `index.html` no navegador.
4. Clique em **INICIAR AVENTURA** e siga as missões. 🎮

Não é necessário instalar bibliotecas ou dependências.

## 🕹️ Como jogar

Na primeira missão, escolha a emoção que melhor representa seu momento. Depois, encontre as **5 estrelas** no campo de estrelas para desbloquear o próximo capítulo. Continue a história até chegar ao final e desbloquear a conquista especial. 🏆

## 💡 Observação

O QR Code da etapa final é carregado por um serviço externo e direciona para uma música no YouTube. Por isso, essa parte precisa de conexão com a internet para funcionar corretamente.
